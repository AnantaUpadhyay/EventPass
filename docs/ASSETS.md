# Assets

Event photography, the admission-ticket mark and paper texture are generated assets prepared for EventPass. Only the web-sized files used by the application are included. Instrument Sans and Newsreader are self-hosted Google Fonts.

Campus festival photographs and official artwork are source-published images, not generated illustrations. Each image has an on-screen credit and archive/edition caption. See [festival image sources](FEST_IMAGES.md) for the original files and publishing pages. Listings without verified imagery stay text-only. Generated legacy demo-event artwork is separate from this university directory.
